# Калькулятор темпа Samarkand Marathon

Сайт для бегунов Samarkand Marathon: ожидаемое время на финише и раскладка темпа по рельефу трассы для всех дистанций — 5, 10, 21,1 и 42,2 км.

**Открыть сайт:** https://tuychiyevnodirbek.github.io/samarkand-pace/

## Что умеет

- **Цель или прогноз.** Задайте целевое время или недавний результат на любой дистанции. Прогноз считается по формуле Ригеля с поправкой на рельеф и температуру.
- **Профиль трассы и темп по участкам.** Видно, где подъёмы и спуски и какой темп держать на каждом участке при ровном усилии.
- **Схема трассы.** Наведите на точку маршрута — покажет, на каких километрах вы там будете и во сколько.
- **Контрольные точки** со временем на часах и запасом до закрытия трассы.
- **Карточка в карман** для заметок или Telegram и советы по каждому участку.
- **Раскладка по каждому километру.**
- **Загрузка своего GPX**, если хотите пересчитать по треку с часов.

Всё работает в браузере, без сервера и регистрации. Настройки запоминаются на вашем устройстве.

## Откуда данные

- Маршруты 21,1 и 42,2 км взяты из официальных GPX-треков SM 2025. Трассы 10 и 5 км собраны по тем же улицам по официальным картам организатора.
- Высоты сняты с официальных профилей на картах организатора для каждой дистанции. Марафонский профиль дополнительно сверен со спутниковой моделью рельефа SRTM 30 м: средняя разница около 5 м.
- Набор высоты по официальным профилям: 42,2 км ≈ 230 м, 21,1 км ≈ 170 м, 10 км ≈ 75 м, 5 км ≈ 95 м.
- Пункты питания взяты с официальных карт.
- Расписание и лимиты указаны по данным организатора на октябрь 2026.

## Как считается

- **Рельеф.** Трасса разбита на отрезки по 50 м. Каждый получает коэффициент усилия по уклону: подъём 1% ≈ +3,5% ко времени, спуск 1% ≈ −2,4%. Время распределяется так, чтобы усилие было ровным. Каждый разворот добавляет около 3 с.
- **Погода.** Выше 12 °C время растёт на 0,12–0,35% за градус в зависимости от дистанции.
- **Прогноз.** Формула Ригеля T₂ = T₁ × (D₂ / D₁)^k, где k от 1,05 до 1,08.

Это ориентир для планирования, а не гарантия результата.

## Как обновить

Весь сайт — один файл `index.html`. Данные трассы лежат в объекте `TRACK` (высоты и координаты через каждые 100 м). Участки, пункты питания и развороты — в объекте `MODEL`, расписание — в `DIST`. После правки достаточно закоммитить файл, и GitHub Pages обновит сайт за минуту-две.
